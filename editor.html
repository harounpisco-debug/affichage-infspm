1. الاتصال بمستودع GitHub

لإنشاء الرمز: على GitHub اذهب إلى Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token، فعّل صلاحية "repo" فقط، ثم انسخه هنا. يُحفظ الرمز محلياً في متصفحك فقط ولا يُشارك مع أي طرف.

هذا الرمز يُستعمل أيضاً لرفع الصور والموسيقى مباشرة من جهازك — لا حاجة لأي حساب إضافي.
